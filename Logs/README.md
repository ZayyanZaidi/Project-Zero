# Logs Memory

This folder contains automated and conversational progress logs generated by the Brain assistant.

## Structure
* `Logs/daily/`: Daily timeline of git commit digests, file modification summaries, and activity recaps.
* `Logs/sessions/`: Work session notes and milestones achieved.
* `Logs/sync.md`: Status of recent file and repository monitor runs.

> The model logs what actually changed, highlighting meaningful milestones rather than raw git diffs.
