# Suggestions & Action Items

This folder contains proactive advice, next-step recommendations, and flagged issues produced by the model in **Work Mode**.

## Structure
* `Suggestions/next-steps.md`: Prioritized task suggestions based on current code progress and git status.
* `Suggestions/issues.md`: Flagged code smells, missing tests, unhandled edge cases, or performance considerations observed during monitoring.
* `Suggestions/archive/`: Resolved or dismissed suggestions.

> **Rule:** The model never writes to your actual codebases. It records all actionable advice here for your review.
