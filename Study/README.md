# 📚 Study & Course Preparation Hub

This directory is exclusively for **coursework, exam preparation, and conceptual mastery**. It is completely separate from software engineering codebases in `Projects/`.

---

## 🏛 Structure

```
Study/
├── Courses/
│   ├── CS-Algorithms/             <- Example course folder
│   │   ├── Syllabus.md            <- Course objectives & exam topics
│   │   ├── Notes/                 <- Lectures, concept breakdowns, summaries
│   │   └── Quizzes/               <- Interactive self-tests generated by Brain
│   └── System-Design/
│       ├── Syllabus.md
│       ├── Notes/
│       └── Quizzes/
└── Quick-Notes/                   <- Quick formulas, cheatsheets, flashcards
```

---

## 🧠 Brain in Study Mode
When you switch Brain to **📚 Study Mode**:
1. It selects your active course from `Study/Courses/`.
2. It quizzes you strictly on course material and syllabus topics.
3. It breaks down complex theoretical concepts with clear analogies and step-by-step notes.
4. All study notes save automatically into the selected course's `Notes/` or `Quizzes/` folder.
